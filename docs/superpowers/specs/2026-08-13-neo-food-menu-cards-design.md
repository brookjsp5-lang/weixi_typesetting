# Neo 菜单卡：美食风模板统一升级设计

## 目标

将现有 12 套美食风模板统一升级为与 TypeZen Neo 界面一致的「Neo 菜单卡」风格。升级只影响美食风输出的微信公众号内联 HTML，不改变模板数量、名称、选择界面或其他六类模板。

## 设计原则

- 延续系统现有的浅暖灰底、细描边、圆角、硬朗小阴影和高饱和主题色。
- 装饰是内容层级的辅助符号，而不是大面积插画；正文保持可读、安静且适合手机阅读。
- 萌宠仅以低频 Unicode 角标出现，用于「主厨推荐」等提示；不引入外链图片、字体或素材。
- 所有元素均由 `section`、现有 HTML 标签和内联 CSS 构成，继续使用显式 `background-color`，以确保微信公众号粘贴稳定及暗黑模式兼容。

## 统一视觉组件

### 标题与小标题

- H1 使用菜单标题牌：主题色顶边、浅色底、细边框与 3px 硬阴影；保留当前左对齐及用户可选的 H1 对齐微调。
- H2 使用带小餐具符号的菜品分区牌，采用主题色边框、圆角和 2px 硬阴影。
- H3 使用主题色短边与小型食物符号，作为配料、店铺信息或子步骤的轻量层级。

### 正文、重点与引用

- 正文维持暖白底与当前行距，避免每段卡片化。
- 加粗内容使用主题色半透明底纹，并保留细边或底线，形成菜单重点标记。
- 引用块统一为「主厨小贴士」卡：顶部标签包含低频猫咪/餐具符号，主题色细边、暖浅底与小硬阴影。

### 清单、步骤与分隔线

- 有序列表继续使用两位步骤编号，但升级为有边框、浅底的菜单步骤牌。
- 无序列表改为简洁的食材/餐具符号与主题色圆点组合，不增加图片资源。
- Markdown 分隔线输出一个居中的菜单花边，由 Unicode 盘子、星点和餐具符号构成，并以 `section` 内联样式实现；不再只输出单条 `<hr>`。

### 图片与表格

- 图片维持当前圆角与描边，在外框上增加低调的主题色硬阴影；不叠加会遮挡照片的贴纸。
- 表格继续采用固定布局和断词规则，只升级表头与行分隔的菜单卡视觉，不改变内容结构。

## 实现边界与数据流

`getStylesByCategory("food", color)` 继续为全部 12 套模板生成共享组件样式。渲染器只在 `template.category === "food"` 时对标题、列表和分隔线输出美食风专属结构；其他分类保持字节级意图不变。

所有装饰均由当前模板主题色及现有 `foodTextColors` 派生，因此番茄、黄油、抹茶等十二种模板只在颜色上变化，组件语言保持统一。

## 兼容性与异常处理

- 仅依赖现有 `marked` 的 heading、list、blockquote、hr 和 image 渲染入口。
- 使用标准 HTML 文本、`section` 和 `style`，不使用 SVG、伪元素、外部 URL、`flex` 必需布局或图片贴纸。
- 继续在外层与块级内容中注入明确背景色；表格保持 `table-layout: fixed` 和单元格换行规则。
- 若微信客户端无法呈现某个 Unicode 符号，内容仍完整可读，装饰不会影响排版或复制。
